拿着 GregTech 的工具（扳手、螺丝刀、软锤、撬棍、锤、电烙铁、剪线钳）或者覆盖板去点 GT 的机器、总线、仓、管道之前看：点在一个面的哪里，作用的就是哪个面（九宫格）。

# 九宫格：点一个面，作用到哪个面
- GT 的方块有六个面（上下东南西北）。拿着工具点一个面时，GT 不只看点的是哪个面，还看点在这个面的哪一点：这个面按 0.25 和 0.75 切成 3×3 九格。
  - 点中间那格：作用在点的这个面上。
  - 点四条边中间那格：作用在挨着那条边的面上（点上表面靠北的那条，作用在北面）。
  - 点四个角：作用在点的这个面的背面（点上表面的角，作用在下面）。
- 所以站在一个面前，六个面都改得到。玩家拿着工具时，客户端会在面上画出这九格；你看不到那张图，是用 use_item 的 side（点哪个面）和 hit（点在哪一点）来选格子。
- hit 是 { x, y, z }，各 0 到 1，从方块最低的角（西、下、北）算起。点的那个面上，垂直于它的那一个数就是 0 或 1（点上表面 y 是 1，点西面 x 是 0），另外两个数选格子：小于 0.25 是靠西 / 靠下 / 靠北的那条，大于 0.75 是靠东 / 靠上 / 靠南的那条，中间是中间。
  - 点上表面（side: "up"），作用到：上 { x: 0.5, y: 1, z: 0.5 }；北 { x: 0.5, y: 1, z: 0.1 }；南 { x: 0.5, y: 1, z: 0.9 }；西 { x: 0.1, y: 1, z: 0.5 }；东 { x: 0.9, y: 1, z: 0.5 }；下（任一个角）{ x: 0.1, y: 1, z: 0.1 }。
  - 点北面（side: "north"，z 是 0），作用到：北 { x: 0.5, y: 0.5, z: 0 }；上 { x: 0.5, y: 0.9, z: 0 }；下 { x: 0.5, y: 0.1, z: 0 }；西 { x: 0.1, y: 0.5, z: 0 }；东 { x: 0.9, y: 0.5, z: 0 }；南（角）{ x: 0.1, y: 0.1, z: 0 }。别的面照这样换。
- 不给 hit 时点的是正中间，作用的就是点的那个面。
- 面的编号（方块数据里的 mFacing、覆盖板的 s）：0 下、1 上、2 北、3 南、4 西、5 东。

# 各种工具点下去做什么
- 下面说的“作用的面”就是上面九宫格算出来的那个面；但**点的那个面上已经装着覆盖板时，作用的就是点的这个面本身**（只有扳手、电烙铁、剪线钳例外，它们一直按九宫格）。
- 扳手：把机器、总线、仓的朝向（输出的那一面）转到作用的面。蹲着用扳手点单方块机器：转的是它的正面（有屏幕的那一面）。
- 螺丝刀：调点的那个面上覆盖板的模式（每点一下换下一种）。螺丝刀不按九宫格：要调哪个面的覆盖板，就点那个面。
- 软锤：让机器停下 / 接着干（点一下切换）。
- 锤（硬锤）：作用的面上没有覆盖板时，蹲着点是切换机器的自动输入、自动输出，不蹲是切换静音；有覆盖板时是调那块覆盖板的工作间隔。
- 撬棍：蹲着点，把作用的面上的覆盖板拆下来，掉在地上。
- 电烙铁、剪线钳：管道和线缆在作用的面上接不接（还有电烙铁切换那一面输出的红石强弱）。
- 装覆盖板：拿着覆盖板**蹲着**点（sneak: true），装到作用的面上（那一面已经有覆盖板就装不上）。不蹲着点会打开机器的界面，不会装上。
- 空手或拿着别的东西点：装着覆盖板的那一面，先交给覆盖板（有的覆盖板会打开自己的界面）；其余打开机器的界面。

# 怎么知道点成了什么
- use_item 点完一个方块，结果里写着这个方块自己存的数据里哪些值变了（data changed: mFacing 1 → 4 这样）。没变的写着没变。机器在跑时一直在变的数（进度、电量）不算在里面。
- 实测（测试服，输出总线（LV））：点上表面中间 mFacing 变 1（上）；上表面靠北 → 2（北）；上表面的角 → 0（下）；上表面靠东 → 5（东）。蹲着拿传送带点上表面靠西 → 西面装上了传送带（覆盖板 s 4）。螺丝刀点西面中间 → 西面那块传送带的模式 d 0 → 1；螺丝刀点上表面靠西 → 什么都没变。扳手点装着覆盖板的西面靠上 → mFacing 变 1（扳手照样按九宫格）。
- 看一个方块现在每个面是什么样：inspect_block（朝向、每个面上的覆盖板）。
