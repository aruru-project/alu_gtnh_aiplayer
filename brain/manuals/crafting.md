主人只给了目标（“做一个 XX”“帮我弄点 XX”），要你自己查配方、挑做法、找材料、合成或者开机器加工时看。

主人只说要什么、没说怎么做时，怎么做由你来定。没有一条现成的“最佳路线”：工具只告诉你事实（有哪些做法、基地里现在有什么机器、东西放在哪），选哪条是你的判断。下面写的是玩家挑做法时会考虑的事，是参考，不是规则；拿不准就问主人。

# 一层层往下查
1. find_item 确认是哪个物品，拿到 id 和 meta（物品名是中文的，直接用主人说的词搜；几个都像时问主人）。
2. find_recipes 看它有哪些做法。结果按加工方式一种种列，不分好坏；每种写着基地里有没有做它的机器、那台机器什么状况。每条配方有一个 # 编号。
3. 挑一条你觉得合适的（怎么挑见下一节），看它要哪些原料。
4. find_in_storage 一次把这几样原料都查了（“any xxx”的用矿辞名查）。它看的是整个基地。
5. 库存里没有的原料，回到第 2 步查它怎么做。这样一层层往下，直到每样东西要么库存里有，要么你知道怎么做。
6. 路线定了、想知道一共要多少底料：写一行程序 `return (await tool('total_materials', { id, meta, count, recipes: [你选的那几条配方的 # 编号] })).text`。它只做乘法（一轮出几个按轮数取整，模具和工具只算一个），不替你选任何一步。
7. 动手：取料（withdraw_items）→ 从最底下那一层做起（craft_item、process_items），一步一个任务。

走一遍的样子（做 1 个直升机桨叶）：
- find_recipes 桨叶 → 手工合成：4 精炼铁柄 + 3 钢螺丝 + 1 钢齿轮，要螺丝刀。
- find_in_storage 这四样 → 螺丝、齿轮、螺丝刀有，精炼铁柄没有。
- find_recipes 精炼铁柄 → 压模机：9 钢锭一根，要模头（转轴）留在机器里。基地有一台进阶压模机，有电。
- find_in_storage 钢锭、模头（转轴）→ 钢锭有，模头（转轴）没有。
- find_recipes 模头（转轴）→ 手工：4 玄钢板 + 1 模头（杆）+ …… → 再查玄钢板、模头（杆）……
- 查到模头（杆）：库存没有，配方要流体固化器和熔融钢，罐子里有什么你看不到。**这里就该停下来问主人**，把查到的这条链说给他：“桨叶要 4 根精炼铁柄，柄要模头（转轴），它要一个模头（杆）——仓库没有，做它要熔融钢。你那有现成的吗？”

# 挑做法时玩家会想什么
- **每个成品耗多少料。** 同一样东西不同做法差很多：钢板卷板机 1 锭 1 板，手工锤 2 锭 1 板。find_recipes 每条配方后面括号里的 per xxx 就是每个成品耗多少。
- **要不要为它新做模具或工具。** 压模机省料，可要是得先为它做一个模头（又是好几步、还要流体），做两个零件就不值得；手边有锤有锯，手工敲两个更快。要得多的时候反过来。
- **会不会用掉现成的机器或成品。** 配方的原料里有一台机器、一件做好的工具或零件时，仓库里那台多半是主人留着用的，不是给你当原料的。先问。
- **流体从哪来。** 单方块机器的罐子你看不到、也灌不了：配方要流体（mB …）时，只有主人已经接好了才做得成。多方块的输入仓看得到（find_machines）。看不到的不要当成有。
- **手工工具配方费料、磨工具。** 有读得懂、确实做得了的机器时，玩家一般走机器；没有时手工是正常的办法。
- **哪些是主人自动化的一部分。** 标着 AUTOMATED 的箱子、总线、机器：从里面取一些通常没事，往里放会和管道送来的混在一起。动之前先问。机器里放着的模具、燃料是主人摆好的，要用先问，用完放回去。
- **没见过的机器。** find_recipes 写 CAN TRY 的（别的 mod 的机器、熔炉）身体读不到状态，只能放进去试；配方没列的东西（熔炉的燃料）要自己带上。见 screens 手册。
- **要一把工具而仓库里没有。** 做一把最简单的就够用（不用做电动的）；用哪种材质看仓库里什么多。
- 一种方式下配方很多（工具每种材质一条，几百条）时，用 way 加 contains 缩小：find_recipes 给 way "有序合成"、contains "钢"。结果一页 10 条，要看完就翻页。想知道一样东西能拿来做什么：库函数 find_uses（不在工具清单里，run_program 写一行 `return (await tool('find_uses', { id, meta })).text`；再给 way、contains 看具体的配方）。

# 卡住了、缺东西时
- 查到某一层不知道怎么继续（没有配方、要的机器没有、流体看不到、几条路你分不出好坏）：把已经查到的链、卡在哪一样、试过什么告诉主人，问他。不要硬编一条路，也不要只说“做不了”。
- 报“缺什么”时报到底：不是“缺玄钢板”，而是做玄钢板那条路上真正没有的那样东西、差多少、卡在哪台机器（没有、没电、电压或炉温不够）。中间那几层怎么来的也顺带说一句，主人手里要是有现成的中间件，给那个也行。
- 主人说“仓库里明明有”：find_in_storage 只看得到已加载区块里的容器，机器和总线里的东西是另算的。问主人东西放在哪，用 at 以那里为中心再查。
- 主人教你的做法、偏好（“板一律走卷板机”“模头去压模机里借”）：一两句的用 remember，成套的用 write_manual 写成你自己的手册，下次照办。
- 多步的目标把进度用 remember 记下来（目标、做到第几步、还缺什么），办完了 forget。
- 说到物品和机器，一律用工具结果里的中文名，原样说，不要自己翻译或换说法。

# 同一种东西两个 id
- GregTech 把登记在同一个材料件矿辞名下的东西当成一种：玄钢锭有 EnderIO 的和 GregTech 的两个 id，矿辞名都是 ingotDarkSteel。机器配方里写的是其中一个，后面标着 (or any ingotDarkSteel)，放哪个都行；高炉出来的也是其中一个。
- 所以库存要按矿辞名查（find_in_storage 的 ore），不要只查配方上写的那个 id。process_items 会自己用你身上有的那种。
- 手工合成里点名某个 id（没有写 any xxx）的格子只认那一个。

# 手工合成（craft_item）
- 给 recipe（配方的 # 编号）和 count（要几个成品）。原料怎么摆由配方定，你不用管。
- 汇总里写着 fits your 2x2 grid 的随身就能做；needs a crafting table 的要工作台或匠魂合成站：不用给 table，工具会找离你那时最近的一个走过去。只有主人点名要用哪个台子时才给 table。
- 原料和工具必须已经在身上。以 no_material 失败时 missing 列出每样还差几个。
- 以 invalid 失败时看消息：附近没有工作台就先走到一个旁边；合成格里有别人摆的东西就换一个；摆好后出来的不是要的东西，是这条配方在这个服务器上不成立，换一条或问人。

# 用机器做（process_items）
- 给 machine（机器的坐标，find_recipes 的 CAN RUN NOW / CAN TRY 后面和 find_machines 里都有；多方块机器给它的主机）、recipe（# 编号）和 rounds（做几轮）。要放什么、放多少、设几号编程电路、预期出什么，工具照配方算。
- 哪个 mod 的机器都行，原版熔炉也行：只要是带界面、能放东西的方块。身体读得懂状态的（GregTech 的）会先告诉你它行不行；读不懂的（find_recipes 写 CAN TRY）就是放进去试，配方没列的东西（熔炉的燃料）要自己加进 inputs。没见过的机器怎么对付，见 screens 手册。
- 消耗的原料要带够（配方的量乘轮数）。模具、模头这类“stays in the machine, not used up”的是物品，要带一个在身上，做完会连同产物取回来。
- **编程电路不用带**：配方里的 programmed circuit N 由工具直接设在机器上（多方块设在输入总线上），做完恢复原样。不要去找、去做编程电路这个物品。
- GregTech 的机器要满足：跑这类配方、等级不低于配方的、有电（蒸汽机器是有蒸汽，读不出来，只能试）、没在忙、没被关。find_machines 能看到每台的状态（默认看你身边 32 格；机器在别处时给 at，以那个地方为中心看）。
- 一批要等一会儿，量大时把 wait 调大。结果里有 timedOut 是没等到做完：做好的已经取回来了，剩下的还在机器里。
- 以 invalid 失败、说机器没开工时，原料已经拿回来了。看结果里的原因：NO POWER、SWITCHED OFF 告诉主人；有电又空闲的，对着配方查是缺模具、缺流体、电压或炉温不够，还是输出口满了，不要原样重试。

## 多方块机器（工业高炉这类）
- find_machines 里标着 multiblock 的是它的主机，下面列着它的输入输出总线和仓。STRUCTURE NOT COMPLETE 的用不了，告诉主人。
- 原料会放进输入总线，产物从输出总线取。高炉的配方有炉温要求（coil heat）：机器的炉温不够的那条，find_recipes 会标 NOT on the machine(s) here。
- 配方要流体（配方里写着 mB … (fluid)）：输入仓已经接着这种流体（find_machines 里看得到仓里有什么、有多少）就不用管；没有的话，带上装着这种流体的单元，用 fluids 给。产物是流体的留在输出仓里，你取不了。
- 输出总线写着 keeps nothing: pushes into … 的，产物会被推到旁边的箱子里：工具会按配方去那个箱子取。
- 总线、仓上标着 AUTOMATED（接着漏斗、管道）的，是主人自动化的一环：输入总线可能一直是满的，放不进去时不要去清它，问主人。

# 还做不了的
- 单方块机器的流体格：你灌不了、也看不到，要它已经接好流体来源（先问主人）。
- 要点按钮才开工的机器：按钮你点不了。格子能点的用 open_screen / click_slot 自己点（screens 手册），还不行就告诉主人。
- find_recipes 里写着 you cannot run this yourself 的方式：那不是机器也不是合成（信息页、在世界里发生的事），得主人来，或者换一种方式。

# 别忘了
- 取料、合成、加工可以一次排好队（排在后面的传 queue: true），每个任务结束时你都会被叫醒；队列里还有任务在等时，不要再用不带 queue 的任务把它们顶掉。
- 步骤多而且一样（做一串中间件、一样样取料）时，可以写一个例程一口气做完，见 routines 手册。
- 为了办主人交代的事，取用他基地仓库里的材料属于正常干活；数量明显大的（要好几组，或者会把某样东西拿光）先问一声。标着 AUTOMATED 的箱子和总线里的东西，动之前先问。
- 仓库、工作台、常用机器的坐标用 remember 记下来，下次直接用。
