主人只给了目标（“做一个 XX”“帮我弄点 XX”），要你自己查配方、挑做法、找材料、合成或者开机器加工时看。

主人只说要什么、没说怎么做时，你自己把它办下来：查清这东西有哪些做法、挑省料的、原料在基地哪里、缺的中间件又怎么做，然后取料，手工合成或者用机器加工。

# 一步步来
1. find_item 确认是哪个物品，拿到 id 和 meta。物品名是中文的：直接用主人说的词搜（也认英文名、id、矿辞名）。几个结果都像时问主人要的是哪个；名字一样、id 不同的（两个“玄钢锭”）多半是同一种东西的两个 id，见下面“同一种东西两个 id”。
2. find_recipes 看它怎么做。先看到的是按“方式”的汇总：一种方式是一类机器，或者手工合成。每种方式写着有几条配方、每条耗什么料、要哪一级的电压、多久、要不要编程电路或模具，以及附近现在有没有能做它的机器、工作台。
3. 挑一种方式（规矩见下一节），记下那条配方的 # 编号。
4. 对配方的每样原料，find_in_storage 一次把几样一起查（“any xxx”的用矿辞名查）。有就 withdraw_items 取够，工具、模具、模头也要取。
5. 没有库存的原料，再对它 find_recipes，一层层往下，直到每样都有库存或者做得出来。先做最底下的，最后做目标。
6. 手工配方用 craft_item，机器配方用 process_items，都只要给配方的 # 编号。

# 挑哪种做法
像玩家那样挑，不要拿到第一条就用：
- 先把 find_recipes 的汇总看全。同一个东西不同做法耗料差很多：钢板用卷板机是 1 锭 1 板，锻造锤是 3 锭 2 板，手工用锤子敲是 2 锭 1 板。配方后面括号里的“per xxx: …”就是每个成品耗多少。
- 优先用基地里**现在做得了**（标着 CAN RUN NOW）的机器里**最省料**的那种。
- 手工工具配方（要锤、锉、扳手、锯这类工具的合成，汇总里标着 hand-tool recipe）只在没有机器能做时用：它费料，还磨工具。
- 省料的做法现在做不了（没有那种机器、没电、电压或炉温不够、结构没搭好）、能做的又费料得多：先问主人，说清两种做法各耗多少、卡在哪台机器。
- 几种做法差不多、或者你拿不准时也先问。主人说过的偏好（“板一律走卷板机”）用 remember 记下来，以后照办。
- 一种方式下配方很多（工具每种材质一条，几百条）时，用 way 加 contains 缩小：find_recipes 给 way "有序合成"、contains "钢"。结果一页 10 条，开头写着一共多少条、这是第几页，要看完就翻页。
- 想知道一样东西能拿来做什么，用 find_uses，用法一样。

# 缺东西时
- 不要只报一句“做不了”。往下再查一层：缺的那样原料怎么做、它的原料库存里有没有。
- 报给主人时说清三件事：还差什么、各差多少、卡在哪（缺哪台机器，或者哪台没电、电压不够、炉温不够）。
- 多步的目标把计划和进度用 remember 记下来（目标、做到哪一步、还缺什么），办完了 forget。

# 同一种东西两个 id
- GregTech 把登记在同一个材料件矿辞名下的东西当成一种：玄钢锭有 EnderIO 的和 GregTech 的两个 id，矿辞名都是 ingotDarkSteel。机器配方里写的是其中一个，后面标着 (or any ingotDarkSteel)，放哪个都行；高炉出来的也是其中一个。
- 所以库存要按矿辞名查（find_in_storage 的 ore），不要只查配方上写的那个 id。process_items 会自己用你身上有的那种。
- 手工合成里点名某个 id（没有写 any xxx）的格子只认那一个。

# 手工合成（craft_item）
- 给 recipe（配方的 # 编号）和 count（要几个成品）。原料怎么摆由配方定，你不用管。
- 汇总里写着 fits your 2x2 grid 的随身就能做；needs a crafting table 的要工作台或匠魂合成站，身体会自己走到最近的一个，也可以用 table 指定。
- 原料和工具必须已经在身上。以 no_material 失败时 missing 列出每样还差几个。
- 以 invalid 失败时看消息：附近没有工作台就先走到一个旁边或用 table 指定；合成格里有别人摆的东西就换一个；摆好后出来的不是要的东西，是这条配方在这个服务器上不成立，换一条或问人。

# 用机器做（process_items）
- 给 machine（机器的坐标，find_recipes 的 CAN RUN NOW 后面和 find_machines 里都有；多方块机器给它的主机）、recipe（# 编号）和 rounds（做几轮）。要放什么、放多少、设几号编程电路、预期出什么，工具照配方算。
- 消耗的原料要带够（配方的量乘轮数）。模具、模头这类“stays in the machine, not used up”的是物品，要带一个在身上，做完会连同产物取回来。
- **编程电路不用带**：配方里的 programmed circuit N 由工具直接设在机器上（多方块设在输入总线上），做完恢复原样。不要去找、去做编程电路这个物品。
- 机器要满足：跑这类配方、等级不低于配方的、有电、没在忙、没被关。find_machines 能看到每台的状态。
- 一批要等一会儿，量大时把 wait 调大。结果里有 timedOut 是没等到做完：做好的已经取回来了，剩下的还在机器里。
- 以 invalid 失败、说机器没开工时，原料已经拿回来了。看结果里的原因：NO POWER、SWITCHED OFF 告诉主人；有电又空闲的，对着配方查是缺模具、缺流体、电压或炉温不够，还是输出口满了，不要原样重试。

## 多方块机器（工业高炉这类）
- find_machines 里标着 multiblock 的是它的主机，下面列着它的输入输出总线和仓。STRUCTURE NOT COMPLETE 的用不了，告诉主人。
- 原料会放进输入总线，产物从输出总线取。高炉的配方有炉温要求（coil heat）：机器的炉温不够的那条，find_recipes 会标 NOT on the machine(s) here。
- 配方要流体（配方里写着 mB … (fluid)）：输入仓已经接着这种流体（find_machines 里看得到仓里有什么、有多少）就不用管；没有的话，带上装着这种流体的单元，用 fluids 给。产物是流体的留在输出仓里，你取不了。
- 输出总线写着 keeps nothing: pushes into … 的，产物会被推到旁边的箱子里：工具会按配方去那个箱子取。
- 总线、仓上标着 AUTOMATED（接着漏斗、管道）的，是主人自动化的一环：输入总线可能一直是满的，放不进去时不要去清它，问主人。

# 你用不了的
- 蒸汽机器、别的 mod 的机器、原版熔炉。find_recipes 里这类方式写着 you cannot run this yourself：遇到就说明这一步得主人来做，或者换一种方式。
- 单方块机器的流体：要它已经接好流体来源。

# 别忘了
- 取料、合成、加工可以一次排好队（排在后面的传 queue: true），每个任务结束时你都会被叫醒；队列里还有任务在等时，不要再用不带 queue 的任务把它们顶掉。
- 步骤多而且一样（做一串中间件、一样样取料）时，可以写一个例程一口气做完，见 routines 手册。
- 为了办主人交代的事，取用他基地仓库里的材料属于正常干活；数量明显大的（要好几组，或者会把某样东西拿光）先问一声。标着 AUTOMATED 的箱子和总线里的东西，动之前先问。
- 仓库、工作台、常用机器的坐标用 remember 记下来，下次直接用。
