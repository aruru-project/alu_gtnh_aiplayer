主人只给了目标（“做一个 XX”“帮我弄点 XX”），要你自己查配方、找材料、合成或者开机器加工时看。

主人只说要什么、没说怎么做时，你自己把它办下来：查清这东西怎么做、原料在基地哪里、缺的中间件又怎么做，然后取料，手工合成或者用机器加工。

# 一步步来
1. 先用 find_item 确认是哪个物品，拿到 id 和 meta。服务器上的物品名是英文的：主人说中文名，你自己译成英文再搜（“直升机背包”搜 copter pack）；搜不到就换个说法，或者只搜最有特点的一个词。几个结果都像时问主人要的是哪个。
2. 再用 find_recipes 看它怎么做。合成配方里每样原料写着：要几个；是一种确定的物品（id/meta），还是“any xxx”（xxx 是矿辞名，任何登记在这个名字下的物品都行）；带 [tool] 的是锤子、扳手、螺丝刀这类工具，合成时要在身上，只磨损不消耗；还有你身上已有几个。机器配方写着机器名、等级、每轮几秒、原料（哪些不消耗）、流体和产物。
3. 对每样原料，先用 find_in_storage 看基地里有没有现成的：一次把几样一起查，“any xxx”的用矿辞名查。有就用 withdraw_items 取够，工具也要取；结果里写着在哪个容器、具体是哪种物品的 id/meta。
4. 没有库存的，再对那样原料用 find_recipes，一层层往下，直到每样都有库存或者做得出来。
5. 有合成配方的用 craft_item，只有机器配方的用 process_items。材料和工具必须已经在身上。先做中间件，最后做目标。

# 手工合成
- 2x2 的配方随身就能做；3x3 的要工作台或匠魂的合成站，身体会自己走到 24 格内最近的一个，也可以用 table 指定。
- craft_item 的结果里 crafted 是做出来的个数。
- 以 no_material 失败时，missing 列出每样原料还差几个：去仓库取，或者查那样原料自己怎么做。
- 以 invalid 失败时看消息：附近没有工作台就先走到一个旁边或用 table 指定；合成格里有别人摆的东西就换一个；这条配方摆不出来、或者摆好后出来的不是要的东西，就换一条配方或问人。

# 用机器做
- 你能用 GregTech 的单方块机器（车床、压模机、组装机这些）。用 find_machines 找：机器的 recipes 和配方里的机器名是同一个词（比如 Lathe），可以用 name 筛。
- 挑的机器要同时满足：等级不低于配方的 tier；有电（has power）；没在忙（idle），也没被关掉。找不到这样的机器就告诉主人缺哪种机器、或者哪台没电，不要硬试。
- 原料取到身上以后用 process_items：machine 给机器的坐标，inputs 列出要放进去的每样东西和数量（配方的量乘以要做几轮）。
- 配方原料里标着不消耗的（stays in the machine, not used up：编程电路、模具）也要带在身上并列进 inputs，数量 1。编程电路的 meta 就是它的编号。做完后它们会和产物一起取回来，所以结果里取回的东西除了产物，还可能有电路、模具和没用完的原料。
- 带流体的配方你处理不了，除非那台机器已经接好了流体：遇到就告诉主人这一步要什么流体。
- 一批要等一会儿，量大时把 wait 调大。结果里有 timedOut 是没等到做完：做好的已经取回来了，剩下的还在机器里做，过一会儿再去取。
- process_items 以 invalid 失败、说机器没开工（did not start）时，原料已经拿回来了。看结果里的机器状态：NO POWER 是没电，SWITCHED OFF 是被人关了，这两种告诉主人；有电又空闲的，是缺电路或模具、缺流体、原料不是这台机器的配方、等级不够，或者输出格满了。对着配方查清是哪一种再说，不要原样重试。
- 只有多方块机器才能做的东西你做不了；蒸汽机器、别的 mod 的机器、原版熔炉也用不了（熔炉烧的东西要有 find_machines 列得出来的电炉才行）。遇到就说明这一步得主人来做。

# 别忘了
- 取料、合成、加工可以一次排好队（排在后面的传 queue: true），每个任务结束时你都会被叫醒；队列里还有任务在等时，不要再用不带 queue 的任务把它们顶掉。
- 不要空转：某样东西既没有库存、你又做不出来时，停下来，一次说清楚缺什么、各缺多少，等主人决定。
- 多步的目标把计划和进度用 remember 记下来（目标、做到哪一步、还缺什么）：每个任务结束后是新的一轮，你靠记忆和对话历史接着做。办完了用 forget 删掉。
- 仓库、工作台、常用机器这类地点的坐标也记下来，下次直接用。
- 为了办主人交代的事，取用他基地仓库里的材料属于正常干活，不用每样都问；数量明显大的（要好几组，或者会把某样东西拿光）先问一声。
- find_item、find_recipes 报 busy 是服务器刚启动、配方索引还没建好，过几秒再试。
