碰到没见过的机器、别的 mod 的机器、原版熔炉，或者任何不知道怎么用的界面（要点格子、要点按钮的）时看。

# 任何带界面的方块你都能用
你用东西的办法和玩家一样：走过去，打开它的界面，把东西点进去、点出来。身体不分是哪个 mod 的。所以没有“这种机器不支持”这回事，只有“身体读不读得懂它的状态”的区别：
- **身体读得懂的**：GregTech 的单方块加工机器和多方块主机（蒸汽的也算）。find_machines 里有它的等级、有没有电、忙不忙；find_recipes 写 CAN RUN NOW（已经比过电压、炉温）。蒸汽机器不烧电，它有没有蒸汽读不出来，写着 steam-powered 的就是放进去试。
- **身体读不懂的**：别的 mod 的机器、原版熔炉。find_machines 把它们列在后面一段（other machines：照配方册认出来的，这个方块是哪种机器、能做哪几类配方）；find_recipes 写 CAN TRY。能用，只是开工之前没人能告诉你它行不行。

# 没见过的机器，按这个顺序来
1. **先直接试 process_items。** 它对任何带界面、能放东西的方块都行：给 machine（那个方块的坐标）和 recipe（配方编号），或者自己写 inputs。身体会把原料点进去，等里面不再变化，把产物格里的东西取回来。
   - 配方里没列的东西要你自己加进 inputs：**熔炉要燃料**（木炭、煤，1 个烧 8 个东西），有的机器要催化剂。
   - 失败说 nothing inside it changed（10 秒里面什么都没变）：它没开工，原料已经回到你身上。多半是缺燃料、没电、没蒸汽，或者这些原料不是它的配方。
2. **不行就打开界面自己看。** 走到它旁边，open_screen 给它的坐标。结果分两段：
   - Its slots：它自己的格子。标着 OUTPUT 的是产物格（放不进东西）；标着 display only 的只是显示（编程电路的设置），里面没有真东西；别的是能放东西的格子（原料、燃料、模具）。
   - Your own inventory：你背包里有东西的格子。
   - 每格前面的 slot 编号就是 click_slot 要的。
3. **自己点。** click_slot：
   - 按着 Shift 点你自己的一格（shift:true）：整组进它“该去的地方”（原料格、燃料格）。最常用。
   - 按着 Shift 点它的一格：整组回到你背包（取产物、把放错的拿回来）。
   - 不按 Shift：左键拿起或放下一整组，右键（right:true）拿一半或放一个。要把东西放进指定的某一格时这样点：先点自己的那格拿起来，再点目标格放下。拿起来的东西在 cursor 上，关界面之前要放下。
   - 每点一次都会给你点完之后的样子，照着看下一步。
4. **用完 close_screen。** 开着界面时别的事都干不了；任务在跑的时候也开不了界面（先等任务结束）。
5. 机器是慢慢做的：点进去以后关掉界面，过一会儿再打开看产物格，或者用 withdraw_items 取（对机器它默认只取产物格；要取原料格里的东西给 fromInputs:true）。
6. **还不行**（界面里没有格子、要点界面里的按钮才开工、点了没反应）：告诉主人卡在哪——是哪个方块、界面叫什么、你试了什么——并用 report_problem 记一条。界面里的按钮（不是格子的那些）你点不了。

# 点哪个面、蹲不蹲
- 有的方块点不同的面、蹲不蹲，打开的界面不一样。open_screen 的 side 是点哪个面（down / up / north / south / west / east），sneak: true 是蹲着点，hit 是点在那个面的哪一点（各 0–1）。给了 side 时你得已经站在那个面的前方（先 go_to 过去）。
- 例：机器某个面上贴着覆盖板“基础槽位扩展”，蹲着右键那个面，打开的是覆盖板自己的 9 格：`open_screen { at: { x: -525, y: 70, z: 41 }, side: "west", sneak: true }`。只是存取里面的东西，用 deposit_items / withdraw_items 带同样的 side、sneak 更省事（containers 手册）。

# 一个方块自己存的全部数据
- 任何方块都能这样看：inspect_block 带 detail: true。结果里是它对扫描器自报的那几行话（GregTech 的机器有），和它存档里的全部数据，原样给出。没有人为某种机器挑过“该给你看哪几项”，所以别的结果里没写到的状态都在这里：机器的各种开关、仓锁定了什么、覆盖板怎么设的、格子里的东西带着什么附加数据。
- 键是这个方块自己起的内部名字（mMode、lockedFluidName、gt.covers……），值是原样的，要你自己读懂；结果末尾会把里面出现的流体内部名、物品 id 对上游戏里的中文名。物品写成 { item, meta, count, name }。
- 数据多时放不下：结果里写着一共多长、每一项多长；用 path 只看其中一项的全部（`path: "gt.covers"`、`"Inventory[3].tag"`）。在程序里 r.data.saved、r.data.says 是全的，可以写个循环把一片机器扫一遍。
- 例：大型化学反应釜说“输出空间不足”，可五个输出仓都是空的。对每个输出仓 `inspect_block { x, y, z, detail: true }`：它的话里有一行 Locked to fluid.gas_gas，存档数据里 lockedFluidName 是 gas_gas——这个仓被锁成只收炼油气，别的流体进不来。五个仓各锁了什么，一比就知道哪种产物没有仓收。
- 这是看，不是动。看懂了“是什么状态”，要改它还是靠界面和右键（open_screen、click_slot、use_item）。

# 凿子（Chisel）
- 凿子是一件拿在手里的工具，不是方块：`open_screen { item: { id: "chisel:chisel" } }` 打开它自己的界面，不用走到哪里。凿子有好几种（find_item "凿子"），它的 meta 是磨损，不用写。
- 玩家的用法：把要变的方块放进界面里放原料的那一格，界面里会出现它那一组的各种花纹，点想要的那个，放进去的那一叠整叠变成那种花纹；再把它拿回背包。一个换一个，不耗别的东西。
- 界面里哪一格是放原料的、花纹各在哪一格，以 open_screen 给你的格子清单为准（每格写着里面是什么）：点之前先看一眼，点完再看结果对不对。
- 哪些方块是一组、要的那个花纹在不在这一组：find_recipes 查那个方块，或者程序里 data.chiselGroupsOf(id, meta)，见 crafting 手册的“凿子的花纹”。
- 这套点法试通了、数量又多（图纸要几千个同一种花纹）时，可以把它写成例程，也可以写成你自己的手册（write_manual）留着下次用。

# 不是界面的：世界里的按钮、拉杆、门
- 这些是方块，玩家是空手右键它。use_item 不给 id、只给 on 就是空手右键那个方块一下：`use_item { on: { x: 7, y: 65, z: 5 } }` 按下那里的按钮（拉杆是扳到另一边，门是开或关）。
- 一个方块上分好几个可点的地方时（一块面板上的几个按钮、抽屉正面的几格），side 说点哪个面，hit 说点在那个面的哪一点（各 0–1）；times 是连点几下。细节和抽屉的例子在 inventory 手册。
- 空手右键一个带界面的方块，界面会打开又被马上关掉（结果里写 it opened a screen）：这只说明它有界面。要留着界面看和点，用 open_screen。

# 界面还能干什么
- 别的 mod 的工作台、要摆格子的机器：一格格点进去。原版和匠魂的 3×3 合成用 craft_item 更省事。
- 身上的东西的界面（背包）：open_screen 给 item。往包里存取东西用 deposit_items / withdraw_items 的 bag 更省事。
- 例程里也能调这几个工具：同样的点法要重复很多遍时写成例程。

# 要小心的
- 机器里原来放着的东西（模具、燃料、别人的原料）是主人的：拿出来之前先问，用完放回去。
- 接着管道的机器（AUTOMATED）是主人自动化的一环，往里放之前先问。
- 点错了就按着 Shift 点回来，不要把东西留在不认识的格子里。
