要去某个地方、走到某个玩家身边、跟着人、传送，或者设 home、回 home 时看。

# 走路
- go_to 走到一个位置：只给 x 和 z 就走到那里的地面；高度有讲究时再给 y。y 是脚站的高度：楼上地板那层方块是 y72，人站在上面就是 y73。给了 y 时 range 也管高度：range 0 就是脚正好在 y、水平正好在那一格。go_to_player 走到某个玩家身边。
- follow_player 一直跟着一个玩家，自己不会结束：要停就 cancel_task，或者启动别的任务。
- 你一次最多步行 256 格左右。更远的地方走不过去（任务会以 unreachable 失败，消息里写着 teleport closer first），要先用 go_home 传送到附近再走。
- 别人说“这里”“我旁边”“过来”时，先用 get_player_position 找到他的位置，不要猜坐标。
- 走路时身体会自己开门（木门、栅栏门、卷帘门这类用手能开的），走过去随手关上；会走楼梯、爬梯子和藤蔓（上去、下来都行），也会坐 OpenBlocks 电梯上下楼。所以要进建筑、要上楼，先直接走过去；走不通（铁门这类只能用红石开的，或者确实没有路）再看失败消息、告诉主人。
- 楼梯和梯子按真人的规矩走：楼梯每一级往上迈的时候，脚下这一级上方第三格不能有东西（不然顶头）；梯子爬到顶，旁边要有能站上去的地板，从楼板的洞口下来也是踩到梯子上。盖楼梯口、梯子口时照这个留空。
- go_to 默认 dig:false、climb:false、maxDrop:3：不挖路、不垫脚、不规划超过3格的落差，无敌也一样。允许额外挖天然方块开路才给 dig:true，仍先尝试不改地形的路；maxDrop 可以明确选0–40格。go_to_player / follow_player 仍按原来的天然方块规则绕路/挖路，climb 单独控制垫脚。
- OpenBlocks 脚手架在本整合包里是有碰撞的普通落脚方块，不当梯子用；两层直柱旁边需要一级台阶，或明确允许垫脚。已有一级台阶时 go_to 能正常登顶。
- 步行不等于飞行控制：已悬停在交互够得着的位置可以操作，够不着则先用移动控制换位或落地。连续空中3秒仍需步行接近会失败，单段步行接近最多90秒。飞行装备可能持续耗油，任务结束、失败、等待都不等于已降落或关闭；要长时间处理别的事，先自行决定是否落地、关机。

# 垫方块
- go_to、go_to_player、follow_player 默认不垫方块。只有给了 climb: true，走不上去的地方才会在脚下叠泥土、圆石往上爬（身上要带着这些方块）。follow_player 跟不上时原地等，task_status 里它的那一行写着为什么（不垫块跟不上也写在那里）。
- 上不去时 go_to 以 unreachable 失败，消息照实说为什么：
  - nothing to stand on at the destination：目标那一格站不住（脚下是空的、格子里有东西、头顶顶着）。消息里写着那几格是什么，多半是坐标给错了一格，或者目标在楼梯口的洞上。
  - no way there without stacking blocks to climb on; one that stacks N exists：不垫方块上不去，垫 N 块能上。要不要垫你自己定，要垫就给 climb: true 再走一次。
- 结果里写着到了哪、脚和你要的高度差几格（dy），路上垫了哪几块、现在还在不在，为了过去挖掉了哪几块。这些都留在世界里了：在别人的地方要说一声，或者回去收拾（dig_blocks）。
- takeBack: true（和 climb: true 一起给）：到了以后把这次垫的、站在那里够得着的方块拆掉；脚下踩着的和够不着的照报坐标，结果里的 notTakenBack 是没拆的个数。

# home 和传送
- 服务器允许随便 /sethome 和 /home。go_home 传送到你设过的 home，是走远路最快的办法。
- 设 home、看有哪些 home 都是发服务器指令：run_command。以后还会回来的地方（仓库、工地、主人的基地），到了就 run_command 发 `sethome 名字`（名字只用字母、数字、_ 和 -），再用 remember 记一条（键写成 home:名字，内容是坐标和用途）：指令本身不会替你记。`home list` 看设过哪些。
- go_home 去一个不存在的 home 会以 invalid 失败：先 run_command 发 `home list` 看名字。
- run_command 能发哪些指令由服务器的允许列表定，你读不到那份列表；不在列表里的会被拒绝，结果里会写明。被拒绝了不要重试，告诉主人。

# 走不到的时候
- unreachable：没有路，或者太远。太远就先传送到附近；否则换一个能到的目标，或者问人。
- stuck：试了多次没有进展（追一个玩家 5 分钟追不上也是它）。先 get_status、look_around 看看情况再重试一次；还不行就问人。
- 被带到别的维度时任务会以 interrupted 失败：先看状态再决定。
